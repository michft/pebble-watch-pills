# Digit font

`Roboto-Bold.ttf`: Roboto Bold, Copyright 2011 Google Inc. All Rights Reserved.
Licensed under Apache 2.0; see `LICENSE-Roboto.txt`.

Unmodified font from the rePebble SDK's Moddable `plug-schedule/fonts` bundle.
Upstream: https://github.com/googlefonts/roboto-2

Only digits are compiled into the three watch resources. The largest size is
104px: two lines plus six pixels of padding fit the Emery display, and each
glyph fits its 512-byte font cache. Larger glyphs can exceed that cache limit.
